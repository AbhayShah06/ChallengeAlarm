# Challenge Alarm

An ad-free Android alarm built around one job: make noise until you solve the math. It has a fast dark alarm list, exact scheduling, one-time or repeating alarms, and five difficulty tiers. Enabled alarms stay at the top, the next alarm is always visible, and the ringing screen is designed for half-awake use. Alarm definitions remain local and survive reboots, time changes, and app updates.

No accounts, ads, analytics, or extra challenge modes are included. Run with Android Studio/Gradle on a machine with JDK 17 and Android SDK 35. Device testing is still needed for exact alarm access, lock-screen/full-screen notification behavior, audio routing, reboot restoration, and vendor battery restrictions.
