# Challenge Alarm

An Android alarm with a compact alarm list, optional weekday repeats, exact alarm-clock scheduling, and a math-gated dismissal. Choose one of five tiers from super easy to very hard. Higher tiers use harder arithmetic and require more correct answers. Alarm definitions are stored locally and restored after reboot, time changes, and app updates. Ringing uses a foreground service, a looping system alarm tone, vibration, audio focus, and a full-screen notification.

No accounts, ads, analytics, or extra challenge modes are included. Run with Android Studio/Gradle on a machine with JDK 17 and Android SDK 35. Device testing is still needed for exact alarm access, lock-screen/full-screen notification behavior, audio routing, reboot restoration, and vendor battery restrictions.
